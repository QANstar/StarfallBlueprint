# 作物植物培养机

植物培养机（`plant_cultivator`）在机内模拟生长：保留一个环境方块和一个植物样本，持续消耗水与相能，循环输出对应产物。无需在世界中铺田、种树或等待随机刻；不检查外部光照、天气和维度。须先自行取得目标植物样本，机器不会解锁尚未取得的物种。

## 制造与运行

工作台配方 `AG-M01`：机器框架1、硼质玻璃2、控制板1、输水管1、铁板2、合格Q0通用晶料1，共8件。Q0须P≥90、I≥20、C=0，控制板同时遵循现有陨相制造门槛。

打开机器后使用三个输入槽：

| 槽位 | 内容 | 使用方式 |
| --- | --- | --- |
| 0 | 环境方块 | 放1个相容方块；保留，不消耗 |
| 1 | 植物样本 | 放1个受支持植物或种子；保留，不消耗 |
| 2 | 水桶 | 自动加入1000mB水，空桶送至成品槽；也可直接用水桶右键机器或接水管 |
| 9—12 | 产物与空桶 | 可手动取出或从底部自动输出 |
| 18 | 小型电池 | 沿用工业设备电池接口 |

无升级时每批400tick（正常20TPS下20秒），消耗250mB水和8000XH；逐tick支付20XH。一桶水可供应4批。输入水罐容量4000mB，不能混入其他液体。环境及样本数量不提高产量；GUI每槽最多1个。上方漏斗可投环境／样本／水桶，侧面可连接水管与能源，底部漏斗或物品能力接口取产品和空桶。

启动时同时检查环境、至少250mB水、至少20XH电与输出空间；条件不足不开始预约。批次开始只扣一次水并固定产物，环境与样本锁定，不能在GUI中换取。在制批次因断电、输出堵塞或停机而暂停；储水耗尽影响下一批，不再重复扣在制批次用水。保存及搬迁保留在制产物、进度和已付能量，无离线补产。红石信号停机，移除信号恢复；培养机没有手动停机或方向设置按钮。

水桶补液独立于种植启动：空间不足容纳完整1000mB或返还空桶时，保留水桶、不补液。空桶占用成品槽，建议底部持续抽取。储水罐满时，槽内水桶保留。

## 支持植物与培养环境

当前显式支持Minecraft 1.21.1的88种样本、86种产物方案。火炬花种子／成花和瓶子草荚／成花分别共用产物方案。默认每批2个产物，表中另列例外。

“土壤”包含泥土、草方块、耕地、灰化土、砂土、缠根泥土和苔藓块。“水生基质”包含沙子、砂砾、黏土块、泥土，以及五种活／死珊瑚块（不含红沙）。所有方案均消耗上述工艺水。

覆盖依据Minecraft 1.21.1植物源码与原版树苗、花卉、村民可种植种子标签核查；花卉标签中的叶子不视为独立植物样本。紫颂植株和活珊瑚块是机器培养扩展，并不表示它们在原版可自行生长或骨粉复制。死珊瑚、任意木材和叶子、幽匿及蛙卵不作为植物样本。

这些是明确的原版方案；不会把任意模组植物自动当成可培养样本，也不会复制种子／环境物品上的任意自定义组件到产物。左侧升级面板默认一个空槽，放入后追加一个空位，槽数不设固定上限，固定大小每页最多6格；接受通用提速与省能接头，所有页数量叠加；不接受熔炉专属扩批模块，也没有骨粉加成。详见[统一升级](MACHINE_UPGRADES.md)。

## 验证状态

此前71样本的120/120项结果保留在[首轮证据](verification/2026-10-23-plant-cultivation-gametest.txt)。88样本扩展已通过121/121项集中服务端验证，包含全部样本的完整生产周期和独立标签／物种覆盖断言，见[开发进度](PROGRESS.md)与[扩展证据](verification/2026-10-23-plant-coverage-gametest.txt)；客户端与压力测试按要求暂缓，第三方植物不自动兼容。
