# 机器统一升级

整备台、辊压机、辊式破碎机、地脉共振仪、相核凝矿阵、植物培养机、精制机、回收机、生辉处理机、自动合成台与并列自动熔炉，共11种加工机支持通用加工升级。储能矩阵还适配公共备用电源、七种发电机、泵与集露设备；能流增幅仅适配其中能够接收能量的设备，发电机不接受。流体容仓仅适配有加工液体端口的设备，包括整备台、相核凝矿阵、精制机、生辉处理机、植物培养机、生辉燃机、泵与集露设备。

主界面左侧常显升级面板，不挤占原料、成品、配方预览或玩家背包。默认只显示一个空槽；每增加一个已占用槽，便保留一个新的追加空槽。只显示已占用槽和唯一追加空位，移除升级留下的空洞会重用，升级槽总数不设固定上限；每格都能放该设备适配的任意升级。

侧栏固定为60×144，每页最多显示6格，使用上一页／下一页访问更多升级，不随槽位数量继续放大。Shift装入先在所有页合并物品及组件相同的堆叠，仍有剩余时再开新槽；效果计算覆盖所有页。

## 加工工时与能耗

令`s1/s2`为超频驱动Ⅰ／Ⅱ件数，`e1/e2`为节能回路Ⅰ／Ⅱ件数，`c1/c2`为高效核心Ⅰ／Ⅱ件数，`n`为省能接头件数。同栈、跨槽、跨页均按实际件数相加，不把多个升级的百分比连续相乘。

```text
速度权重 w = s1 + 2×s2 + c1 + 2×c2
省能权重 q = n + 2×e1 + 4×e2 + 2×c1 + 4×c2
工时 = max(1, ceil(基础刻数 × (100 + 10×e1 + 20×e2) ÷ (100 + 25×w)))
增耗预算 = ceil(基础批次能耗 × (100 + 10×s1 + 25×s2) ÷ 100)
最终批次能耗 = ceil(增耗预算 × 9 ÷ (9 + q))
```

节能回路Ⅰ／Ⅱ单件的能耗分别约为基础的81.82%／69.23%，工时分别为基础的110%／120%（向上取整）。高效核心Ⅰ／Ⅱ保持相同省能效果，工时分别约为基础的80%／66.67%，自身没有增耗与减速惩罚。混装时其他升级仍承担各自负面效果。

例如，基础40刻／4000 XH的自动合成批次，超频驱动Ⅰ为32刻／4400 XH；节能回路Ⅰ为44刻／3273 XH；高效核心Ⅰ为32刻／3273 XH。直接混装超频驱动Ⅰ与节能回路Ⅰ得到36刻／3600 XH，不能得到高效核心的无负面效果。

只有1件省能接头时耗能为基础的90%，2件约81.82%；原矿整备使用1件接头仍为200刻／36000 XH。省能只降低加工能耗，不增加发电量或改变燃料热值、品质和基础产率。

并行冶炼权重`b=Ⅰ级件数+2×Ⅱ级件数`，最大并列路数为`2+2b`，每路耗能系数再乘`1+0.05b`。每路真实消耗一套普通熔炉配方，来料和四格输出空间决定实际开工次数；产物、容器余物和经验均按实际配方次数结算。扩批不作用于其他加工机。未装升级时为2路／400刻；单件并行冶炼Ⅰ／Ⅱ分别为4／6路。

## 储能、接收与液槽扩展

每类扩展权重均为`Ⅰ级件数+2×Ⅱ级件数`。储能及液槽容量为`基础容量×(1+0.5×权重)`，充电接收上限为`基础接收上限×(1+0.25×权重)`，均受整型存储上限约束。例如2件储能矩阵Ⅰ加1件Ⅱ使容量变为基础的3倍。普通机器基础储能320000 XH，公共备用电源为2000000 XH，生辉燃机为1000000 XH；液槽基础容量为每槽4000 mB。

能流增幅改变真实能量端口的每刻接收预算，多个方向及多次调用共享该预算；实际充电仍受电源、线路、剩余容量及机器自身充电效率限制。液体扩容同时更新真实液槽和液体端口容量。扩展设备读档时先恢复升级，再恢复容量与存量。

空闲状态下才能装卸。若取下某一堆扩容升级后，当前能量或任一液槽存量超过剩余容量，则拒绝取下；先消耗电量或排出液体后即可拆卸，手动取放与Shift遵守同一限制。整备台兼容旧版内部能量单位，其历史尾数不会因容量判定而丢失。

## 高效核心配方

配方使用既有材料，产出均为1个对应核心。`conductor`是导相铜复材板，`board`是基础控制板，`insulation`是普通绝缘基材，`directed`是精密导相晶片，`substrate`是铜／硼隔离基底。

| 产物与路线 | 材料 |
| --- | --- |
| 高效核心Ⅰ | 超频驱动Ⅰ×1、节能回路Ⅰ×1、基础控制板（`board`）×1、导相铜复材板（`conductor`）×2、普通绝缘基材（`insulation`）×2 |
| 高效核心Ⅱ：直接合成 | 超频驱动Ⅱ×1、节能回路Ⅱ×1、基础控制板（`board`）×2、精密导相晶片（`directed`）×1、铜／硼隔离基底（`substrate`）×1 |
| 高效核心Ⅱ：Ⅰ级升级 | 高效核心Ⅰ×1、超频驱动Ⅰ×1、节能回路Ⅰ×1、基础控制板（`board`）×1、精密导相晶片（`directed`）×1、铜／硼隔离基底（`substrate`）×1 |

两条Ⅱ级路线均补充高阶控制、定向和隔离材料；升级路线可利用已有Ⅰ级核心。配方整合只保留两种升级的正面效果，由机器按高效核心计效，不按两个普通升级重算负面效果。

## 采矿组合与批次快照

采矿专属升级仅用于地脉共振仪，相核凝矿阵不接受。富矿采集按实际原版方块掉落表结算，只对支持时运的来源生效，不对所有产物套固定增产倍率。精准采集与富矿采集、炽热熔炼互斥，安装时拒绝冲突；富矿采集可以与炽热熔炼组合。

炽热熔炼先计算普通或时运掉落，再对能匹配实际熔炉配方的产物转换；不能熔炼的产物保持原样。每件实际参与转换的输入增加100 XH，先加入采矿基础能耗，再统一应用超频增耗与节能权重。额外能耗按实际转换件数计算，不按模块件数收取；重复安装不重复熔炼。

开工时确定掉落、随机种子、时运等级、精准／熔炼状态及最终工时与能耗，并保存本批快照。读档续作不重新抽取掉落，不重算已预约预算；来源、真实配方及快照必须一致，不能通过修改来源或冲突升级绕过配方限制。输出不够放时不开工，不先消耗原料或电量。

## 装卸、供能与旧存档

升级保留不消耗，通用与专属升级可混装。没有在制批次时才能装卸；断电、满仓或红石暂停仍属于在制，全部升级格保持锁定。批次开始冻结工时与耗能，旧在制批次沿用原预算；不因加载、拆移或换装重算已预约产物。物流、漏斗与自动化不暴露升级格，手动与Shift遵守同一适配与单格数量限制；分页不限制可装升级的总槽数。

大量超频会提高工作步耗能。当单步预算超过机器内部电量缓存时，分次交付的电量会计入并保存已付预算，付足该步后再推进进度；实际速度仍受供电或熔炉供热速率限制，不会因缓存容量不足永久卡死。

旧NBT索引继续兼容：stock16／17／20／21、共振仪18、整备台19中的原有升级保留；超出这些历史位置的额外升级独立存入NBT。旧接头、熔炉升级及广谱共振无需重新制作。界面上的分页位置不作为固定存档槽位编号，保存和加载后仍保留所有升级。
