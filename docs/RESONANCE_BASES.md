本页为当前规则。2026-10-26 13:41:47完整构建及186/186项真实服务端测试通过，见[本轮证据](verification/2026-10-26-phase-array-gametest.txt)。早期35种基底直接产模组矿与单格有限钻采方案均已被后续规则替代；169、180项验收保留为历史。

## 基础共振与广谱升级

地脉共振仪保持2×2×1四格。机器四格下方放4块同种共振基底，正前方两格留空。每块基底在普通工作台定形合成：外围8块同种来源方块、中央1份陨相原矿，得到1块对应基底；不能用粗矿替代矿石方块。基底不消耗、不挖空世界、不提供区块加载。

基础档仅支持石头→4圆石，铜矿／深层铜矿→1粗铜，铁矿／深层铁矿→1粗铁，共5种基底。

升级槽放入1个“广谱共振升级组件”后，开放其余原版石材与矿物。组件保留不消耗，只能在批次结束后取放；物流不会抽取或装入升级组件。每批200刻／10秒、4000XH，后侧或底部出料。原版矿物范围包括：

- 煤、铜、铁、金、红石、青金石、钻石、绿宝石的普通及深层矿石：对应矿物各1份，铜铁金产粗矿。
- 下界金矿石→1金粒，下界石英矿石→1下界石英，远古残骸→1远古残骸。
- 紫水晶簇→4紫水晶碎片，不复制紫水晶母岩；镶金黑石→1金粒，萤石→4萤石粉。
- 12种石材：石头、深板岩、花岗岩、闪长岩、安山岩、凝灰岩、方解石、黑石、玄武岩、末地石、下界岩、黑曜石，各产4份对应石料；石头和深板岩分别产圆石和深板岩圆石。

共34种原版来源基底：基础5种、升级29种。广谱组件使用钻石、精制晶料、导相材料、控制板、金锭和烈焰粉，数量与九宫格以图鉴为准。L26混凝土蓝图继续使用石头基底，无需升级。

任何档位都禁止陨相、赤钛、灰硼等模组矿。原四种模组共振基底仅保留注册及存档，停用配方及生产；旧在制模组矿共振批次冻结，不能换基底或安装升级继续产出。旧矿石方块及正常精准采集行为仍保留。

缺电、背压、红石、结构不完整或环境不满足时暂停。已预留原版批次保留自己的产物，换基底只影响下一批；高级批次需持续保有升级组件。

## 相核凝矿阵

机器改为真正的2×2×2八格整体，上下两层；一个机器物品一次放置完整结构。放置前需预留八格空间，拆任意部位只返还一个保存库存、水、电及批次的机器物品。上下层共用一个控制器，水管、电缆和底部成品抽取均可接代理外壳；没有独立生产加倍。前方无需像共振仪一样留出作业空格。

底层四格的正下方铺4块同种专用凝矿基底：

| 基底 | 每批产物 | 固定品质 |
| --- | --- | --- |
| 陨相凝矿基底 | 陨相原矿1 | 品位12%、I58、C0 |
| 赤钛凝矿基底 | 赤钛原矿1 | 原有默认质量 |
| 灰硼凝矿基底 | 灰硼原矿1 | 原有默认质量 |

三种基底与原版共振基底采用不同的制造路线。先制凝矿框架，再用框架定相为某种专用基底；每份配方均为九件输入，产一件，一台阵列需要四块同种基底。

1. **凝矿框架**：钢制固定件4、精制晶料1、导相材料2、控制板1、钻石1。九宫格为`SRS / CBC / SDS`，S钢固定件、R精制、C导相、B控制板、D钻石。
2. **定相基底**：导相材料2、烈焰粉1、对应原矿2、凝矿框架1、耐温玻璃2、钻石1。九宫格为`CSC / MFM / GDG`，C导相、S烈焰粉、M原矿、F框架、G耐温玻璃、D钻石。

机器本体另行制造：精制晶料2、机架1、导相材料1、控制板1、耐温玻璃1、钢制固定件2、钻石1，`RFR / CBG / SDS`定形九宫格，产一台。制造依赖陨相衍生的精制、电控与导相材料，并增加钻石和下界材料投入；不是起步采矿的替代。

运行每批400刻／20秒、500mB普通水、80000XH，产对应原矿1份。开工只扣一次水，电量每刻支付200XH。基底永久保留；没有世界矿源扫描、矿块消耗或钻头要求。产物Origin记录机器实际维度，不复制基底制造用原矿的品质。陨相仍须整备与精制；高品位和高完整度自然采矿仍有用途。月络等未来矿物继续关闭。

新批次要求八格完整、四块专用基底同种、水电及完整输出空间有效。缺电、满仓和红石暂停，恢复后沿原批次继续；存档保留已付电量和待产物，换基底只影响下一批。普通地基、混放、缺基底、原版共振基底和旧退役模组基底均不能开工。

## 旧存档与施工

沿用原机器注册ID读取已有存档。旧单格机不会在加载时自动扩建或覆盖邻近方块；拆下重新放置，即按八格尺寸装配。旧工具槽有遗留物品时保留取回入口，空闲后可取出，拒绝新插入，也不再磨损工具。

旧`drill:`批次在旧版本已消耗了源矿，因此允许按保存的待产物和账本结算一次；不会再次采矿、扣水或磨损工具。结算后旧单格机仍不能开新工，直到玩家重新装配完整结构和专用基底。

蓝图必须包含完整八格，材料表只计一个机器物品；四种旋转、上层保护取消及回滚均验证。既有四格机器仍只要求四格结构，不接受无效上层外壳编号。
