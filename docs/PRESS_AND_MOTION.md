# 电动辊压机与轻量动画

铁板手工配方保持：竖排两铁锭合成两铁板。铜锭一份合成铜板一份，可先手工准备机器零件。

新增单方块电动辊压机：1铁锭→1铁板，1铜锭→1铜板。每批2秒、1000XH，自动识别原料，不用切模式。顶部进锭、底部出板，侧面接电，红石暂停。欠电、堵塞、存档和搬迁保留批次，不产生免费金属。

机器由机架1、活塞1、铁板2、普通钢2、控制板1、钢制固定件1、铜板1九件装配。游戏配方册和HTML图册可查；L27提供风机、供料箱、辊压机和成品箱的可下载蓝图，需要上游供锭。

采石机钻轴、破碎机两侧辊面、风机叶片采用四组共享图集动画，辊压机复用辊面。每2刻切帧，关闭插帧；停机用静态图。没有新增实体、粒子、方块实体渲染器或逐帧网络同步。四格机器只在开停变化时更新部件状态。动画原始RGBA帧合计196608字节（不含mipmap及图集开销），所有同类机器共用；未做FPS基准测试。

160项真实NeoForge GameTest通过，涵盖手工配方、1:1守恒、单方块占地、固定端口、红石暂停、存档恢复、背压、四格开停同步及L27真实漏斗风力运行。独立客户端两帧截图确认四种机器实际变化，界面与模型无缺失贴图。见[模型](machine-motion-a.png)、[另一帧](machine-motion-b.png)、[界面](press-interface.png)与[验证记录](verification/2026-10-25-press-motion.txt)。
