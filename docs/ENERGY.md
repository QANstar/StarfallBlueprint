# 能源获取与热源利用

本文按当前能源扩展实现说明运行规则。本轮完整构建及114/114项真实服务端测试通过，范围见[验证证据](verification/2026-10-23-energy-gametest.txt)；客户端与压力测试未执行。

## 发电途径

| 设备 | 能源或条件 | 发电功率 |
| --- | --- | --- |
| 余烬供能机组g01 | 认可的熔炉燃料，包括煤、木炭、木制燃料、烈焰棒、煤炭块和岩浆桶；模组燃料读取NeoForge物品燃烧时间 | 最高500XH/t |
| 鸣风机g02 | 有天光、上方露天；Y低于96／至少96 | 80／160XH/t |
| 流相水轮g03 | 相邻流动水，共享可追溯水源 | 100XH/t |
| 辉光板g04 | 有天光、白天且露天；晴天／下雨 | 100／50XH/t，夜间停止 |
| 生辉燃机g05 | 生辉液，每mB提供1000XH，每刻最多2mB | 最高2000XH/t |
| 熔流发电机g06 | 六面相邻至少一格流动岩浆；静止岩浆源和水不直接驱动 | 200XH/t |
| 地热发电机g07 | 正下方点燃篝火／点燃灵魂篝火／岩浆块／岩浆源 | 40／60／80／160XH/t |

单位为星衡XH；正常20刻／秒。实际发电取决于缓存空间，实际输出还受端口和网络预算约束。工具能匣与公共备用电源只储存能量。

## 余烬燃料与容器

每个有效熔炉燃烧刻对应200XH；每种物品的真实燃烧时间来自NeoForge，以熔炼配方类型查询，可接受其他模组通过该API提供的燃料。不是把所有可燃方块都强行认作燃料，零或负燃烧时间不接受。单份能量上限为整数最大值，防止异常燃烧时间溢出。

| 常见燃料 | 熔炉燃烧刻 | 单份总能量 |
| --- | ---: | ---: |
| 木棍 | 100 | 20,000XH |
| 普通木板 | 300 | 60,000XH |
| 煤／木炭 | 1600 | 320,000XH |
| 烈焰棒 | 2400 | 480,000XH |
| 煤炭块 | 16000 | 3,200,000XH |
| 岩浆桶 | 20000 | 4,000,000XH |

燃料放燃料槽13；顶部、侧面可自动投料。燃料只在开始使用时扣一份，尚未转化为电量的余燃随NBT保存与拆移。缓存满时不消耗下一份燃料。

真实燃料容器余物放入成品槽9—12，可从界面取走或由底部漏斗／物品能力取走。余物空间不足时不消费新燃料、不授予该份余燃；已开始的燃料仍可继续发电。岩浆桶返回空桶一次，不通过重复取出或重载复制。当前岩浆燃烧入口为物品岩浆桶，不新增管道注入岩浆功能。

本轮只扩展余烬发电燃料；整备台、混料炉、并列炉的既有燃料规则不随之扩展。

## 熔流发电机

把流动岩浆布置到机器六面相邻位置；仅岩浆源相邻不发电。水也不能驱动它。机器检查已加载位置，沿上方或更高液位追溯岩浆源；同一可追溯源在同一刻只为一台熔流机提供200XH，多台共享源不叠加，独立来源可分别发电。此共享规则与水轮独立。

机器不抽取、消耗或生成岩浆，只利用流态，工作时可用电缆取电；这不是完整流体动力模拟。机器不加载远处区块，最多追溯64个已加载上游位置；孤立流、路径截断或找不到真实源时不发电。

## 地热发电机

只看机器正下方一格，热源数量不叠加；热源变化在下一次工作刻生效。

- 普通篝火必须点燃：40XH/t。
- 灵魂篝火必须点燃：60XH/t。
- 岩浆块：80XH/t。
- 岩浆源：160XH/t。
- 熄灭篝火、流动岩浆、水或其他方块：不发电。

热源不消耗，无需加桶；属于简化热源利用，不模拟温差、冷却或篝火燃料损耗。环境发电功率低于主动消耗岩浆桶的余烬机组，二者提供不同供能选择。

## 制造与接线

熔流机EN-G06：基础机架1、普通钢2、耐温玻璃2、陶瓷护套1、钛粉1、铜锭1、Q0通用晶料1，共9件。

地热机EN-G07：基础机架1、铜锭2、铁锭1、耐温玻璃1、陶瓷护套1、硼盐1、Q0通用晶料1，共8件。

普通工作台按整件放置，Q0晶料缺失或品质不合格不匹配。配方布局与图鉴共用RE_BFL的规范数据，实际以同步图鉴为准。新机沿用通用工业界面、红石／手动停机和保存拆移。

普通电网共享输送预算2048XH/t；全由强化母线接头组成的网络预算32768XH/t，各机组仍遵守自身端口上限。更高网路容量不会提高单台发电功率。区域必须加载，不离线补算发电。
