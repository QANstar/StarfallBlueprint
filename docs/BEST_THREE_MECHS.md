# 贝斯特三机与组件成长

2026-11-12：水神计划的可制造机体缩减为SG-E涓流工程机、SG-C激湍战斗机、SG-X归海全能机。只保留三种机体注册，不提供旧版整机、知识或存档兼容。

## 开始与操作

1. 在背包“成长”学习基础工务、整备与相关驾驶知识，回工务装配台制造基础机。涓流沿用工程驾驶前置；激湍武装控制只要求野外整备，不强制学习工程驾驶。
2. 工务装配台的水神制造页提供组件、基础武装部件、汇流总成和两种新增机体。全部使用本人主背包及快捷栏的真实材料，不接公共自动合成。
3. 可选学习沧澜三项工程强化或怒涛三项战斗强化；制造组件，将已隔离、存活的收纳机甲持于主手，在安装页选择对应组件。拆卸页返还实物。每项只装一件，工程与战斗各有三项，归海有三个最终强化位。
4. 两种基础驾驶知识均具备后学习归海汇流装配。准备两台隔离、存活、货舱清空的基础机、两类汇流总成和高阶通用材料，选择归海融合。不要求先学或安装任何可选强化。
5. 学习各最终组件及其所用前期组件知识，制造并安装镇渊、天瀑、长川；三者可并装，均保留归海工程与射击能力。

机甲按原方式充电、部署、驾驶、下车、隔离和收纳。WASD驾驶，G主作业（工程机采掘，战斗机射击，归海采掘），V独立火控射击，H工程驻车支撑，Shift下车。键位可在设置中修改。归海自带不可拆出的基础钻掘能力；工程扩展组件含内建九格钻掘能力，不额外赠送可拆钻臂。

| 天瀑 | 强化射击伤害、射速与冷却 |

配方按[设计总纲](../../RE_BFL/04_游戏设定/19_水神计划与机甲谱系.md)接入。归海消耗涓流和激湍各一台、工程和武装汇流总成各一件，以及普通钢64、承相32、导相16、感相8、控制板8、钢制固定件16、陶瓷护套16。

工程汇流总成复用钻切器、整备包、诊断器；武装汇流总成复用火控器、装甲和散热件。镇渊消耗工程扩展与长时作业，天瀑消耗协同火控与持续输出，长川消耗机动驱动与结构防护。融合返还前两机的组件及可拆配装，能继续用作最终组件材料。

工具与储能物品作为制造材料时须完好、无储能；先取出能源、维修再交料。制造与拆装均先在库存副本验证，材料不足、返还空间不足、状态不合格时不扣材料、不改变机体。

## 合成与拆装状态

融合将输入能源相加，超过容量则拒绝；按两机生命比例换算归海生命，沿用较高磨损、热量与冷却，累加工作计数及已付燃料。计数进位折算磨损，无法无损容纳则拒绝。核心实物返还，已付燃料暂存在归海，重新装入核心后继续使用。新机获得独立身份并保留两机来源。

组件安装不补生命、不充电、不清除冷却；降低生命上限的拆卸按比例降低当前生命，不能反复拆装治疗。储能超过拆卸后的容量时须先消耗能源。

## 当前边界

战斗能力为服务端直射武器，执行瞄准、方块遮挡、伤害、电耗、热量、磨损及冷却；本批未新增飞弹实体或独立弹药种类。三机共用现有机甲骨架与工具臂模型，以配色和界面区分。救援、团队支援目前通过区域清障、货舱、结构、冷却、机动及现有整备体现，专用吊运动画、医疗搬运和团队治疗机制仍属后续扩展。真人客户端外观、操控和多人验收需另行记录。
