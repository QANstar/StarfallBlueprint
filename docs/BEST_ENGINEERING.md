# 贝斯特轻型工程首批

本批图册与资源范围为贝斯特工务装配台（best_workbench）、轻型助力骨架（best_frame）、工程钻切器（best_cutter）的原创纹理、模型、中英名称与人工装配资料。由产线图册/build_atlas.py调用best_expansion.py生成；程序资源由tools/sync_catalogue.py与tools/generate_catalogue_resources.py同步。运行时玩法、服务端与客户端验收以程序仓库本轮记录为准，本文不表示客户端测试通过。

## 公共装配台与个人装配

公共工作台配方BEST-M01：基础机架1、普通钢基材2、铁板2、基础控制板1、钢制固定件1、木板2，共9件，每格扣1件。摆法为钢／铁板／钢，机架／控制板／固定件，木板／铁板／木板。装配台本体允许普通合成。

骨架、钻切器仅在专用菜单人工适配装配，个人学习校验，不开放普通工作台或机器配方，不支持自动制造。其材料记录在物品manual_assembly元数据，未加入公共recipes列表，避免被现有自动合成或机器配方注册器收录。

## 装备、供能与维修边界

骨架占腿部装备位，无护甲加成，使用原创64×32裤装UV穿戴纹理：透明间隙之间为开放式金属外骨骼支架。骨架与钻切器各有200000XH内部缓存，出厂为空；潜行按住右键，每刻从背包库存s01工具能匣转入512XH，不再施加二次折损。共享装备仍要求使用者本人已学习对应知识，学习状态保存并在死亡后克隆保留。

| 参数 | 轻型助力骨架 | 工程钻切器 |
|---|---|---|
| 作业能力 | 地面疾跑速度＋15% | 铁级单点采掘，有效方块速度12，为铁镐2倍 |
| 能耗 | 实际助力时16XH／刻 | 每个非零硬度方块256XH |
| 发热 | 实际助力时＋6／刻，含冷却净＋4／刻 | 每个非零硬度方块＋120 |
| 耐久消耗 | 每100个实际工作刻扣1 | 每个非零硬度方块扣1 |

两件工务耐久均为1200；磨完停机，物品保留。热量达到1000时过热停机，冷至400解锁；背包携带或穿戴每刻自然冷却2。电量、温度和耐久分别结算，不能用维修代替补能。

维修每次消耗普通钢基材1，恢复200耐久；将设备脱下并携带于背包，持待修设备于主手，在装配台专用菜单维修。维修不生成新装备，不作为普通合成配方，也不凭此增加电量。

## 本轮验证结果

完整构建及216/216项真实NeoForge服务端GameTest通过，包含12项贝斯特专项，覆盖个人学习／死亡克隆、装配事务、维修保留数据、菜单有效性、真实破块扣费、冷却锁、跨能匣共享补能预算与骨架助力撤除。843份JSON、全部PNG引用、245条图册配方和17条原版映射检查通过；完整生成链1378文件重复生成字节稳定。首轮两处旧测试夹具更新后全量通过。客户端穿戴、菜单及多人实机验收尚未进行；详情见[本轮验证记录](verification/2026-10-28-best-engineering.md)。
