# 白湾自治邦

在配方书搜索能力激发机，或打开创造物品栏的「白湾自治邦」分类。右键打开激发机，任选一系免费觉醒至 F 级。空间系从瞬间移动开始，电系从感应充电开始。高阶技能要求学会所有连线前置技能，并达到指定评级。

选择已学能力后点击对应的快捷键按钮装入能力槽。四槽默认使用 F6、F7、F8、F9，可在 Minecraft 的「选项 → 控制 → 按键绑定 → 白湾自治邦」改键。手持接口重调晶片右键激发机可换系，生存模式每次消耗一枚。两系各自保存评级、熟练度、技能等级及槽位。换系时应先离开自空域。

## 成长与算力

- 每次成功施放积累对应技能熟练度和人物评级训练进度。激发机可消耗经验等级学习新技能，或同时消耗经验和熟练度升级。技能最高五级，并受当前评级限制。评级按 F、E、D、C、B、A、S 提升，每次提升增加基础算力上限和回复。
- 每个 32 格内的辅助计算单元加 8 点算力上限和每秒 1 点回复。自空域中的单元给区域主人提供相同的远程加成，在自空域内只计一次。
- 在露天摆放发射台，手持算力卫星右键发射。携带卫星算力终端，蹲伏右键开启或关闭卫星链路。每颗已发射卫星增加 18 点上限和每秒 2 点回复，跨维度生效。

## 空间系

| 评级 | 能力 | 操作及效果 |
| --- | --- | --- |
| F | 瞬间移动 | 向视线方向瞬移。瞄准生物时传到其身后的安全位置。 |
| E | 空间斩 | 朝视线内的首个目标斩击。 |
| E | 随身空间 | 打开私人储物，升级增加容量。底排为唤物射击备弹。 |
| D | 传送门 | 连接两个可站立的位置。主人直接穿越，其他玩家蹲伏进入。 |
| E | 空间弹射 | 沿视线弹射自身，短时免受坠落伤害。 |
| D | 空间拉取 | 把目标拉到自己身旁的可用空间。 |
| B | 空间崩坏 | 崩解目标周围的方块。三级起将掉落物放入随身空间，装满后留在原地。可采集掉落物受手持工具影响。 |
| D | 唤物射击 | 发射随身空间底排备弹。武器提高伤害，普通备弹落地可拾取，TNT 爆炸造成伤害。 |
| C | 空间位移 | 暂时获得创造式飞行，可再次施放提前取消。 |
| C | 空间禁锢 | 暂时把瞄准的生物固定在原地。 |
| B | 空间屏障 | 在持续时间内抵销有限次数的直接攻击和爆炸。 |
| B | 自空域 | 进入独立建造区域或返回原地。瞄准其他玩家且双方蹲伏可传送访客。区域内所有玩家也可用 `/baiwan return` 返回。 |

自空域使用同一个专用虚空维度，每位拥有者分配互相隔离的 256×256 区域。内部离开边界时会返回原维度。存档保存个人等级、槽位、储物、卫星和自空域设备。

## 电系

电系额外消耗电荷。感应充电靠近通电电路时收益更高，也可用背包里的红石粉提高补充速度。

| 能力 | 前置 | 效果 |
| --- | --- | --- |
| 感应充电 | 觉醒 | 补充电荷。 |
| 定向电击 | 感应充电 | 短程单体电击。 |
| 电驱加速 | 感应充电 | 突进并短时间加速。 |
| 定向供电 | 感应充电 | 给瞄准的机器端口注入 FE。 |
| 连锁电弧 | 定向电击 | 在相邻目标之间跳跃。 |
| 持续感电 | 定向电击 | 对一个目标施加多段伤害。 |
| 绝缘护场 | 电驱加速 | 减轻有限次数的直接攻击与雷击伤害。 |
| 电路扫描 | 定向供电 | 标记视线内的电路和机器能量端口。 |
| 麻痹放电 | 连锁电弧 | 大幅降低一个目标的移动速度并削弱攻击。 |
| 贯穿雷枪 | 连锁电弧、持续感电 | 直线穿透多个目标。 |
| 电爆波 | 连锁电弧、绝缘护场 | 以施法位置为中心扩散，击退敌人。同一目标每次施法受击一次。 |
| 神经超频 | 电路扫描 | 在持续时间内加快算力回复。 |
| 雷暴齐射 | 麻痹放电、电爆波 | 向选中区域降下 25 至 81 道落雷，分波结算。 |
| 多路馈电 | 神经超频、电爆波 | 将固定的能量总量分配给目标及相邻设备。 |
