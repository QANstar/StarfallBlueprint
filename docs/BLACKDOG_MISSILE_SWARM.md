# 黑狗战甲：追猎蜂群飞弹组件

物品 ID：`starfall_blueprint:blackdog_component_swarm`。

在个人研发中解锁浮游炮科技后，可在装甲部件制造台制造：8 层相合金、3 层相晶、3 电路板、30000 XH。组件装入 III 级肩部基底，占用 3 接口与 3 核心负载。也可直接在创造物品栏取得组件。普通装甲最多同时安装 12 个功能组件。创造专用全装腕表预装全部 13 个组件，并有额外肩部接口；旧的全装腕表进入玩家背包后自动补装蜂群，保留原有电量、身份和部署状态。

部署战甲，手持黑狗火控终端，用原有模式切换键或潜行右键选择「追猎蜂群」。

- 按住右键，将准星对准 64 格内的活体目标。敌对、中立、友好以及自己的宠物都可以锁定。
- 连续瞄准 16 游戏刻（正常 20 TPS 时约 0.8 秒）完成锁定，期间有逐步提示音，完成时有确认音，动作栏显示锁定状态。
- 瞄准目标时，目标身上显示橙色四角锁定框与进度条，完成锁定后变为绿色。只有使用技能的玩家能看到；松手、失锁、切换模式或收回战甲后消失，不会给目标附加共享发光效果。
- 锁定后允许少量瞄准偏移；准星偏离目标约 5 度以上（近处另有 0.6 格容差）、视线被方块遮挡、目标死亡或超出距离会失去锁定。重新瞄准需重新计时。
- 锁定后松开右键消耗 16000 XH，并从两侧交替发射 16 枚飞弹，每枚间隔 3 游戏刻（约 0.15 秒）。飞弹先向两侧上方展开，再转向追踪移动目标。
- 未锁定时松手不会发射或扣费。释放瞬间再次检查准星、视线、目标、战甲和电量；服务器独立决定目标。
- 发射后可移开准星；目标死亡或离开维度、玩家死亡、战甲收回或失去工作电量会停止后续发射。目标失效时已发出的追踪飞弹自行消失。

沿用普通飞弹的实体外形、尾焰、伤害及爆炸规则；新增模块拥有独立的物品图标、提示文字、火控模式和快捷键绑定入口。
