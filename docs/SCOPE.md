# 本模组开发范围

自2026-10-28起，StarfallBlueprint定位为可独立游玩的探索、工业与科技模组。剧情内容和剧情玩法由另行开发的独立模组负责；本文取代旧开发文档中将剧情列入本模组后续计划的约定。

## 本模组负责

- 矿物、材料、加工配方、机器、能源、物流、生产自动化与工程建造。
- 工具、装备、维护、专业技术学习及阵营科技路线的功能实现。
- 上述玩法所需的界面、配方手册、技术进度、存档与多人同步。
- 支撑资源探索与技术玩法的世界生成；是否开放未来维度内容仍按各专项范围决定。

阵营名称、技术风格和材料体系可以沿用设定集。阵营科技在本模组中表示技术路线，不实现剧情阵营关系或剧情身份。

## 独立剧情模组负责

- 主线、支线、章节、剧情任务及其目标、提交、奖励与状态流转。
- 剧情人物、剧情NPC、对话、演出、过场与脚本事件。
- 剧情地点与任务场景、阵营剧情选择、声望关系、入团及剧情结局。
- 由剧情完成情况触发的技术开放或其他叙事进度规则。

折桥救援、白灯安置、本星调查及游子入团等属于独立剧情模组的内容，不列入本模组开发或验收清单。

## 统一个人成长

玩家背包的“成长”标签是技术与个人知识的统一入口，贝斯特17项、岭川16项共33项知识全部可见。学习按前置交付材料与经验；制造、装配和维修在设备上单独结算。以后新增技术继续接入同一目录与支付事务，不另造分散菜单。详细规则见[统一成长与科技](PROGRESSION.md)。

## 两者的边界

本模组可单独安装和游玩，不以前置剧情模组、完成任务、对话或剧情身份作为自身技术玩法的必要条件。技术成长使用材料、工艺、设备和个人技术学习等玩法条件；贝斯特的基础工务、工程钻切、野外整备三级学习、独立轻载通行及工务诊断知识、人工装配与设备隔离检修属于技术玩法，继续保留。可驾驶工程机甲也以个人驾驶知识、实际机体、基地供能与现场维护作为前置，沿用材料学习和人工装配，不绑定剧情许可；首个通用模块槽支持实物散热／强化驱动模组与无动力装卸，沿用本人驾驶知识。独立工程臂槽支持钻切／挖掘实物臂、隔离装拆及对应单方块工程作业，不新增剧情或个人知识门槛。机体具有随存档与收纳保存的真实货舱，强化机体作为独立实物升级，增加结构、蓄能与载货容量，并改变移动代价；装拆、货舱访问和扩展格腾空均属于技术维护条件，不增加知识或剧情门槛。独立核心槽的固燃发电核心沿用本人驾驶知识，消耗货舱中的实际燃料补充电量，受发热、磨损、隔离与燃烧余额约束，属于供能技术玩法。独立行走槽的巡航轮组沿用本人驾驶知识，以平地运输效率与越障能力的取舍形成实物配装；隔离装拆及状态保留属于技术维护，不增加剧情门槛。涓流与激湍分别通过组件强化，随后消耗两台基础机和汇流总成制造归海，再安装最终强化组件。重型专用九格钻掘臂沿用个人驾驶知识和工程臂装拆规则，按实际成功方块逐次结算并遵循世界保护、触及范围和电热约束，属于工程技术作业。沧澜区域挖掘臂沿用相同装拆、区域逐块保护与费用机制，专门处理铁铲可采的土方，既有驾驶知识即可操作，不新增个人或剧情门槛。本次作业的物品掉落优先进入有效货舱，余物按原规则落地，沿用已有驾驶知识与掉落保护，不增加自动拾取周边物品或额外剧情条件。专用吊运、医疗与其他技术扩展按实际实施状态推进，不增加独立机型。

水神计划只包含涓流工程机、激湍战斗机、归海全能机三种机体。沧澜／怒涛为可选基础强化组件，镇渊／天瀑／长川为最终强化组件，不保留旧机体或旧存档迁移。技术本体负责制造、装配和资源结算；人物、订单、事故调查和剧情抉择由设定集及独立剧情模组负责，不能倒灌为基础技术的任务门槛。

水神计划机甲的制造升级、维修、补能、货物管理、驾驶和作业须遵循跨机型统一交互约束：同类操作保持入口、逻辑和反馈一致，实用简洁并重视驾驶操控；仅最终归海允许必要且适度的区别。新增功能须对照既有机型及权限、安全和资源规则，不因此承诺自动充电、自动搬运或绕过保护。现行三机与组件操作范围详见[水神计划技术路线](BEST_WATER_GOD_PLAN.md)。

现有工务终端的独立物资交易、配方手册和技术进度属于功能内容，继续保留，不据此扩展剧情任务系统。设定集中的人物、历史和剧情文稿继续作为共享创作资料保留，不代表本模组需要实现这些内容。

独立剧情模组未来可以调用本模组的物品、设备和技术能力。具体联动接口、依赖关系与剧情限制由后续需求另行确定，本次不新增接口或跨模组实现。
