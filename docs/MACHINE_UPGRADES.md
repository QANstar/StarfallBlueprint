# 机器统一升级

11种加工机使用主界面左侧常显升级面板：整备台、辊压机、辊式破碎机、地脉共振仪、相核凝矿阵、植物培养机、精制机、回收机、生辉处理机、自动合成台与并列自动熔炉。面板不挤占机器原料、成品、配方预览或玩家背包。默认只显示一个空槽；每增加一个已占用槽，便保留一个新的追加空槽。只显示已占用槽和唯一追加空位，移除模块留下的空洞会重用，升级槽总数不设固定上限；每格都能放该机器适配的任意模块。

侧栏固定为60×144，每页最多显示6格，使用上一页／下一页访问更多模块，不随槽位数量继续放大。Shift装入会先在所有页合并同类组件相同的堆叠，仍有剩余时再开新槽；效果计算覆盖所有页。

| 模块 | 适配 | 每格数量 | 叠加效果 |
| --- | --- | --- | --- |
| 通用提速Ⅰ／Ⅱ | 全部11种加工机 | 64 | 权重分别1／2；同栈、跨槽与两个等级合计 |
| 基础省能接头 | 全部11种加工机 | 64 | 按同栈与跨槽总件数降低耗能 |
| 熔炉扩批Ⅰ／Ⅱ | 仅并列自动熔炉 | 64 | 权重分别1／2；增加实际加工路数 |
| 广谱共振升级组件 | 仅地脉共振仪 | 1 | 任一格安装即可开放进阶基底；重复安装不额外增产 |

提速权重w=Ⅰ级件数+2×Ⅱ级件数；工时为ceil(基础刻数×100÷(100+25w))，至少1刻。提速耗能系数为1+0.10×Ⅰ级件数+0.25×Ⅱ级件数。各等级效果相加，不把多个模块的倍率连续相乘。

省能接头共n件时，总耗能再乘9÷(9+n)；1件为90%，2件约81.82%。没有提速模块时，原矿整备使用1件接头仍为200刻／36000XH。接头只降低加工能耗，不增加发电量或改变燃料热值、品质和产率。

熔炉扩批权重b=Ⅰ级件数+2×Ⅱ级件数，最大并列路数为2+2b，每路耗能系数再乘1+0.05b。每路真实消耗一套普通熔炉配方，来料和四格输出空间决定实际开工次数；产物、容器余物和经验均按实际配方次数结算。扩批不作用于其他加工机。未装模块时为2路／400刻；单件扩批Ⅰ／Ⅱ分别为4／6路；单件提速Ⅰ／Ⅱ分别为320／267刻，保留原来的单件配置效果。

模块保留不消耗，通用与专属模块可混装。没有在制批次时才能装卸；断电、满仓或红石暂停仍属于在制，全部升级格保持锁定。批次开始冻结工时与耗能，旧在制批次沿用原预算；不因加载、拆移或换装重算已预约产物。物流、漏斗与自动化不暴露升级格，手动与Shift遵守同一适配与单格数量限制；分页不限制可装模块的总槽数。

大量提速模块会提高工作步耗能。当单步预算超过机器内部电量缓存时，分次交付的电量会计入并保存已付预算，付足该步后再推进进度；实际速度仍受供电或熔炉供热速率限制，不会因缓存容量不足永久卡死。

旧NBT索引继续兼容：stock16／17／20／21、共振仪18、整备台19中的原有模块保留；超出这些历史位置的额外升级独立存入NBT。旧接头、熔炉模块及广谱组件无需重新制作。界面上的分页位置不作为固定存档槽位编号，保存和加载后仍保留所有模块。
