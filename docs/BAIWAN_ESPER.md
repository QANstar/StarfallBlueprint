# 白湾自治邦

在配方书搜索能力激发机，或打开创造物品栏的「白湾自治邦」分类。摆放并接入电网，右键打开技能树。空间系从瞬间移动开始，电系从感应充电开始。高阶技能要求学会所有连线前置技能，并达到指定评级。

选择已学主动能力后点击对应的快捷键按钮装入能力槽。被动能力学会后自动生效，不占槽位，并随时间积累熟练度。默认按 K 开关能力模式，开启后右上角显示算力和技能。四槽默认使用 F6、F7、F8、F9，可在 Minecraft 的「选项 → 控制 → 按键绑定 → 白湾自治邦」改键。手持接口重调晶片右键激发机可换系，生存模式每次消耗一枚。两系各自保存评级、熟练度、技能等级及槽位。换系时应先离开自空域。

## 成长与算力

- 每次成功施放积累对应技能熟练度和人物评级训练进度。生存模式学习和升级消耗经验等级及设备电力，升级还需要熟练度。技能最高五级，并受当前评级限制。评级按 F、E、D、C、B、A、S 提升，每次提升增加基础算力上限和回复。
- 每个 32 格内的辅助计算单元加 8 点算力上限和每秒 1 点回复。自空域中的单元给区域主人提供相同的远程加成，在自空域内只计一次。
- 在海岬天阶发射台消耗算力卫星、运载火箭和 200,000 XH。携带领航者终端，在其界面开启对应个人或队伍星座的算力链路。每颗在线卫星增加 18 点上限和每秒 2 点回复，跨维度生效。

## 空间系

| 评级 | 能力 | 操作及效果 |
| --- | --- | --- |
| F | 瞬间移动 | 向视线方向瞬移。瞄准生物时传到其身后的安全位置。 |
| E | 空间斩 | 远程群斩可见目标，按下消耗 8 点算力。长按每 0.5 秒群斩一次，消耗 1 至 3 点算力，取决于空间共振等级。松开或算力耗尽时停止。 |
| E | 随身空间 | 打开私人储物，升级增加容量。底排为唤物射击备弹。 |
| D | 传送门 | 连接两个可站立的位置。主人直接穿越，其他玩家蹲伏进入。 |
| E | 空间扭曲 | 替代空间弹射。沿视线重创直线上敌人，把至多 64 个普通实心方块移至两侧不规则环带。按共享地形预算分刻完成，不复制、不产生掉落，保护容器、流体、基岩和无权限区域。旧技能等级及槽位继续沿用。 |
| D | 空间拉取 | 把视线内 22 至 38 格的目标拉到自己身旁的可用空间。 |
| B | 空间崩坏 | 长按在视线指向处生成球体，持续禁锢并伤害敌人，4 秒后满蓄引爆。提前松开可按蓄力比例引爆。爆炸会分批破坏球内普通方块，保留容器、流体、基岩和受保护方块。 |
| D | 唤物射击 | 短按从侧方发射一个底排物品，每蓄力 0.25 秒增加一个，数量受技能等级和备弹限制。命中或飞行结束回收到随身空间。 |
| C | 空间位移 | 按下消耗 10 点算力并立即开启创造式飞行。每 2 至 4 刻消耗 1 点，取决于空间锚定等级。再次施放或算力耗尽时退出，退出后短时保护坠落。 |
| C | 空间禁锢 | 暂时把视线内 26 至 42 格的生物固定在原地。 |
| B | 空间屏障 | 再次施放或算力归零前持续开启，退出能力模式时也有效。闲置不扣算力，拦截弹射物扣 5 点，近战或爆炸按伤害的两倍向上取整，最低 2 点。第一人称视野边缘会偶尔出现轻微波纹，近战命中时有局部冲击纹和格挡音效。 |
| E | 空间锚定（被动） | 降低持续飞行的算力消耗，无需装备。 |
| C | 空间共振（被动） | 降低空间斩和崩坏球持续消耗，无需装备。 |
| B | 自空域 | 进入独立建造区域或返回原地。瞄准其他玩家且双方蹲伏可传送访客。区域内所有玩家也可用 `/baiwan return` 返回。 |

自空域使用同一个专用虚空维度，每位拥有者分配互相隔离的 256×256 区域。内部离开边界时会返回原维度。存档保存个人等级、槽位、储物、卫星和自空域设备。

## 电系

电系以积蓄电荷、施加感电和消耗电荷输出为循环。总电荷容量为 80 + 感应充电等级×10 + 静电积蓄等级×8。静电积蓄每秒回复 2 至 6 点，被动上限 20 至 52；主动回充可以突破被动上限。感应充电基础冷却降至 1.2 秒，靠近通电电路时收益更高，也可用背包里的红石粉提高补充速度。

用持续感电标记敌人后，电系命中可每目标每 0.5 秒回充一次；电荷回收被动提升回充量并奖励电系击杀。突进靠近感电目标、绝缘护场受到攻击，也能回充。全部电系视觉使用自定义蓝色分叉电弧、白蓝亮芯和电弧环，不使用原版电火花或闪电实体。

| 能力 | 前置 | 效果 |
| --- | --- | --- |
| 感应充电 | 觉醒 | 快速主动补充电荷。 |
| 静电积蓄（被动） | 感应充电 | 有被动上限的自动积蓄，并增加总容量。 |
| 电荷回收（被动） | 持续感电、静电积蓄 | 提升感电命中回充量，并在电系击杀时回收电荷。 |
| 定向电击 | 感应充电 | 短程单体电击。 |
| 电驱加速 | 感应充电 | 突进并短时间加速。 |
| 定向供电 | 感应充电 | 给瞄准的机器端口注入 FE。 |
| 连锁电弧 | 定向电击 | 在相邻目标之间跳跃。 |
| 持续感电 | 定向电击 | 对一个目标施加多段伤害。 |
| 绝缘护场 | 电驱加速 | 减轻有限次数的直接攻击与雷击伤害。 |
| 电路扫描 | 定向供电 | 标记视线内的电路和机器能量端口。 |
| 麻痹放电 | 连锁电弧 | 大幅降低一个目标的移动速度并削弱攻击。 |
| 贯穿雷枪 | 连锁电弧、持续感电 | 直线穿透多个目标。 |
| 电爆波 | 连锁电弧、绝缘护场 | 以施法位置为中心扩散，击退敌人。同一目标每次施法受击一次。 |
| 神经超频 | 电路扫描 | 在持续时间内每秒主动积蓄额外电荷。 |
| 雷暴齐射 | 麻痹放电、电爆波 | 向选中区域降下 25 至 81 道落雷，分波结算。 |
| 多路馈电 | 神经超频、电爆波 | 将固定的能量总量分配给目标及相邻设备。 |

空间位移和长按技能进行期间暂停自然算力回复。退出能力模式、换系、打开其他操作界面或输入中断会清理持续施法；长按输入有服务端超时保护。
