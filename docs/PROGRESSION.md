# 制作说明书

说明书收录营地工业、贝斯特工务、岭川黑狗战甲和海珈轨道航空的设备用途、操作方法与相关章节。打开后直接查阅，正文不显示学习按钮、研究费用、经验、奖励或个人知识状态。

## 打开与查阅

首次登录自动获得“星落蓝图 · 制作说明书”；已有存档玩家下次登录补发一次，背包满时在下次登录重试。右键新说明书或原有营地手册，均打开同一界面；也可以点击生存背包或创造物品栏旁的“说明书”。

顶部分类为全部、营地、贝斯特、岭川、海珈。左侧目录和右侧正文分别使用滚轮翻阅。“相关章节”保留设备与部件之间的流程联系，仅用于查阅。营地手册原有的起步材料、机器配方、供水、发电和产线说明完整收录在“营地”分类。

## 个人设置

说明书顶部固定显示“个人设置”按钮，位于“返回背包”左侧。点击后显示两个独立开关：

- **超能力破坏方块**：关闭后，本人的坍缩挖掘和空间方块位移不改动地形。
- **黑狗战甲能力破坏方块**：关闭后，本人的黑狗采矿炮与导弹不破坏地形。

两个开关默认开启，按钮直接显示当前开启／关闭状态。设置只影响本人，保存于服务端玩家数据，重进和死亡后保留。关闭地形改动后，武器效果和实体伤害继续生效；其他玩家及普通工具挖掘不受影响。

## 制造流程

制造和装备使用直接按实际材料、设备、装配、电量、温度、耐久与库存空间检查。目录按以下顺序介绍设备，玩家可随时翻阅：

- 营地：辅矿与普通熔炉 → 整备台、合金混料 → 结构与电控 → 能源、供水与自动化产线。
- 贝斯特：基础工务 → 工程钻切、野外整备 → 跨步与诊断 → 三种机体、组件和最终强化。
- 岭川：层相材料 → 分级基底与能源核心 → 各类功能组件 → 装配、火控与充电。
- 海珈：无线输能 → 卫星装配与入轨 → 星座供能、束流、动能投射与气象 → 航空设备。
