## 从一块矿，到一座营地

- **用辅矿建立工坊**：铁镐采赤钛与灰硼，先用普通熔炉制取辅料，再用整备台提高产出；制作绝缘材料、耐磨镶片与探索装备。
- **探索陨相矿脉**：在主世界地下发现普通与深层矿石。不同品位影响加工产量，时运附魔可增加原矿掉落，并提高获得高品位原料的机会。
- **建立基础生产**：用整备台将原矿加工为通用晶料，再通过省能接头降低后续生产消耗。
- **加工结构与电控材料**：用普通工作台和熔炉制作铁铜板、普通钢、陶瓷与绝缘料；获得陨相晶料后制作控制板、发电设备与产能模块，继续建设自动化。钢坯由合金混料炉加工。
- **改造随身装备**：从钛制耐磨到陨相加固，再到可选复合强化；用辅矿制造寻矿与采样装备，准备下一阶段探索。
- **统一学习成长与科技**：从玩家背包“成长”标签进入贝斯特与岭川个人研究，交付材料与经验等级；旧进度保留，驾驶知识也在同一面板学习。当前共23项，详见[统一成长与科技](docs/PROGRESSION.md)。
- **学习贝斯特工务**：用开放配方制作轻型装配台，在成长面板学习知识后回工位装配轻型助力骨架和工程钻切器；继续学习野外整备，制造便携整备包在外维修，或回装配台用水桶冷却设备；学习轻载通行后，可为骨架装配跨步组件，在疾跑助力与一格跨步档之间选择；也可独立学习工务诊断，用诊断器检查故障，回装配台隔离设备后检修并重新接通。见[贝斯特轻型工程](docs/BEST_ENGINEERING.md)。
- **驾驶工程机甲**：完成个人轻载通行和工务诊断学习后，在成长面板学习驾驶后，回装配台制造机体；从基地供能方块为打包机体充电，部署后乘坐，以WASD驾驶、G键使用工程臂。机体保存电量、温度、磨损与结构生命，停机后可下机、隔离、检修和回收；可在唯一通用槽安装散热模组或强化驱动模组，在持续作业与高耗能机动之间选择。独立工程臂槽支持拆装原装钻切臂，或换用耗电发热更低的挖掘臂处理土砂；右臂外观、作业费用及收纳状态随实际装配变化。机体自带真实9格货舱，也可安装强化机体扩为18格、提升结构与蓄能上限，并承担更慢、更耗能的移动代价；货物随保存与收纳保留，机体损毁后单独掉落。独立核心槽可安装固燃发电核心，用货舱燃料为机体补能，增加发热与发电磨损；剩余燃烧时间保留，隔离、热锁、满载或磨损停机时暂停。独立行走槽可装巡航轮组，以更高平地速度、更低移动电热，换取从一格降为半格的跨步能力，适合道路运输。在成长面板学习进阶工程后，可主手持隔离、存活的SG-E1涓流收纳机甲，在装配台补足材料并晋升SG-E2沧澜，继承能源、当前生命、货物和配装，已装强化机体套件返还；晋升不会免费修复损伤。沧澜上限为300点结构生命、6000万XH储能与27格货舱，基础／强化驱动速度提升至0.26／0.34，基础／散热模组冷却为每刻4／6，固燃核心每工作刻发电2000XH；更大的实际体型需要宽阔道路与完整支撑，仍有更高移动电热代价。沧澜不再接受初代强化机体套件，还可安装九格钻掘臂，按瞄准面处理最多3×3方块，使用钻石级工具判定，逐块执行保护检查并按成功数量支付电量、发热和磨损；电热不足时停止，不处理方块实体。沧澜另可装区域挖掘臂，以铁铲规则按瞄准面清理最多3×3铲类方块，每个成功方块支付18000XH、18热和1磨损，沿用40刻共享冷却；中心不满足条件时整次不启动，邻块逐一检查保护与触及范围。工程臂作业产生的正常物品掉落优先进入当前有效货舱，满舱余物正常落地；不吸取周围已有物品，也不改变原经验掉落。完整模块化、更多重型专用部件与武器臂继续后续开发。
贝斯特工程线已落实水神计划的“涓流→沧澜”名称与实物晋升，保留原物品和实体ID以兼容旧存档；旧沧澜可继续驾驶，新晋升须本人学习进阶工程。后续“激湍→怒涛”武装线、两线最终融合“归海”全能机及“镇渊／天瀑／长川”强力扩展仍按科技树推进。详见[水神计划技术路线](docs/BEST_WATER_GOD_PLAN.md)。

- **按配方自动制造**：自动合成台从库存汇总材料，接入物流和电力后持续生产，无需手动摆放九宫格。
- **分档共振原版矿物**：地脉共振仪支持34种原版基底，基础5种产圆石、粗铜和粗铁；安装广谱共振组件后开放其余29种，包括紫水晶与远古残骸。四块同种基底永久保留。见[共振与凝矿](docs/RESONANCE_BASES.md)。

- **循环培养植物**：保留环境方块与植物样本，用水和电持续产出作物、花草、原木及水生植物。
- **搭建营地补给**：利用储水罐、集雨器与漏斗连接供水和加工设备，让简单工坊逐步持续运转。

## 开始游玩

在 **Minecraft 1.21.1** 中安装 **NeoForge 21.1.262**，使用 **Java 21**，将本模组 JAR 放入实例的 `mods` 文件夹；联机时客户端与服务端均需安装。当前不需要其他前置模组。

进入世界后，用**纸与圆石**合成营地工务手册，查阅基础配方。先用铁镐采赤钛与灰硼，普通熔炉制取辅料，制作探索装备；再用铁镐采陨相矿并逐步建设加工与供水设备。矿石出现在新生成的主世界区块。

当前版本为 **0.1.0 开发原型**。本仓库暂以源码构建为交付方式，构建方法见下方文档。能源、物流与公共精制已接入；未来维度内容按专项计划预留。剧情内容由独立剧情模组开发。

旧版单格设备需拆移重放为完整凝矿阵，不会自动扩展或覆盖环境；已预约旧批次保留待产物并仅结算一次。遗留工具槽仅供空闲后取回旧物品，不再接受插入。
