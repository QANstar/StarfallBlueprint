# 水神计划：贝斯特机甲技术路线

## 水神计划：现行发展方向（2026-11-02修订）

本节规定后续设计方向。型号使用“初代／进阶型”表示技术成长，不再用轻重体量定义升级等级；正式称呼优先采用机名与型号。后文各批次参数与验证记录保留为当前程序现状。贝斯特全部机甲同源于“水神计划”：承相驱动、工业河谷治水与矿难救援的技术积累分化为工程和武装路线，并在末期汇合。水神是研发计划代号，不表示神力、魔法水属性或只能水下作业；供能继续遵守实际电力、燃料、散热与维护规则。

| 谱系 | 拟定型号与名称 | 成长关系 |
|---|---|---|
| 初代工程 | SG-E1“涓流” | 矿难救援、钻掘、运输的起点；现有best_mech对应这一阶段原型 |
| 进阶型工程 | SG-E2“沧澜” | 由涓流全面升级，继承工程能力并提升结构、承载、供能、机动与持续作业；现有best_heavy_mech仅为阶段原型 |
| 初代武装 | SG-A1“激湍” | 同源初代平台的独立武装分支，发展武器、装甲和火控 |
| 进阶型武装 | SG-A2“怒涛” | 由激湍全面升级，继承并强化战斗能力 |
| 最终全能 | SG-U“归海” | 沧澜与怒涛两线成熟成果共同参与实际融合装配，完整保有工程与武装能力；阵营顶点或接近顶点 |
| 顶点扩展 | “镇渊”／“天瀑”／“长川” | 分别强化重载救援与结构维持、火力火控、机动续航与团队保障；均保留归海全能底座 |

以上型号与名称为统一命名提案，技术架构按此方向执行。进阶型不是用机动性能降低换大容量的平行选项：同职责、同等级配装的基础速度与操控不得低于其初代前身。材料、外形尺寸、总功率和整备规模可以增加，但不能以“取舍”为由取消全面升级。高阶专业部件仍可有各自合理负载。

工程与武装在中期独立制造、培养和使用，兼容部件按接口说明；最终需要两条成熟技术成果与实际机体／核心部件共同装配成一台归海，不是二选一，也不是解锁一边后免费附赠另一边。最终机体具备两类独立接口及完整能力，不再用一个互斥工程臂槽伪装全能；作业模式、火控安全、电热和补给约束管理同时输出，不能删除另一分支基础功能。镇渊、天瀑、长川提供强力新扩展与组合空间，接口数量、数值和并装规则后续设计。

当前程序仍是旧名轻／重型工程平台、各自独立制造与既有单工程臂槽；重型速度0.14／0.18低于轻型0.22／0.28。尚无初代至进阶型升级流程、武装平台、双线融合、归海或顶点扩展，也没有本节命名的游戏内改名。本次只修订设计与剧情资料，不把规划写成已实装或已有验收。

后续优先顺序改为：初代→进阶型实际升级与旧机状态迁移、进阶型机动和持续供能补齐 → 工程作业闭环与独立武装分支 → 双线进阶型成熟与融合装配 → 归海全能接口及强力扩展。升级／融合应保留合法部件、货物、名字与已付燃料，失败整笔不变；不能复制机体、免费治疗、补电或清除磨损。旧物品与实体资源ID保持兼容，显示名称按映射迁移。

剧情通过水神计划的救援订单、军用改造、负载试验与战后再整合连接玛莎、岑野及相关责任调查；危机仍是自然晶层和战争设施连锁失稳，不能把所有责任归给一个计划。技术路线不以剧情结局或游子身份为本体前置；具体人物、任务与叙事解锁由独立剧情模组承载。
