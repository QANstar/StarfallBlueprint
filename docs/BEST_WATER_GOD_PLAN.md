# 水神计划：贝斯特机甲技术路线

水神计划只保留涓流工程机、激湍战斗机、归海全能机。两种基础机可选装沧澜／怒涛组件，随后消耗两台基础机与汇流总成制造归海，再用前期组件制造镇渊／天瀑／长川最终强化。可选分支不是归海的必修前置。

不保留旧整机、代际晋升或旧存档兼容。现行操作、配方及能力边界见[三机指南](BEST_THREE_MECHS.md)，基础工具与配件见[贝斯特工程指南](BEST_ENGINEERING.md)，研究费用见[统一成长与科技](PROGRESSION.md)。

完整研发背景、人物与责任设定见[设定集水神计划](../../RE_BFL/04_游戏设定/19_水神计划与机甲谱系.md)。技术路线不绑定剧情任务或游子身份，剧情由独立模组承接。
