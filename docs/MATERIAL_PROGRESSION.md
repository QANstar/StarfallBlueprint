# 材料与制造阶段

当前版本以“辅矿起步 → 陨相探索与升级 → 精制复合 → 可选后期特化”组织制造。配方可以自然使用，不另设教学签到、免费教学包或虚构剧情解锁；任务人物的运行时接入仍待后续开发。阶段设计服务既有救援、安置、调查与重建主线。

## 用铁镐建立起步工坊

赤钛矿、灰硼矿在主世界Y=-32至80生成，铁镐及以上可采，木镐和石镐不能获得原矿。普通和深层替换使用同一辅矿方块；本轮不改变生成次数、矿团大小或世界种子配置。时运Ⅰ／Ⅱ／Ⅲ仍可增产至1—2／1—3／1—4份，超过Ⅲ按Ⅲ计算。

- 普通熔炉：赤钛原矿1 → 钛粉2；灰硼原矿1 → 硼盐2，各200刻。初期用少量原矿就能制取装配材料。
- 整备台材料模式：赤钛原矿1＋250mB水 → 钛粉10；灰硼原矿1 → 硼盐10，灰硼保留干式无水加工。两者各200刻／40,000XH。同量原矿的产出是普通熔炉的5倍。
- 普通工作台：铜板1＋硼盐1 → 隔离基底2；纸1＋硼盐1 → 绝缘基材2；小麦1＋黏土球1 → 粘结剂2；陶瓷1＋钛粉1 → 护套2。小麦＋黏液球可选增产为4份粘结剂。

整备台潜行空手右击可进入材料加工模式，在配方选择中选赤钛或灰硼工序；普通右击回到陨相原矿模式。材料模式原料走顶部、侧面进燃料、底部出产物。

普通熔炉产辅料不需要整备台。整备台自身保持3铁、1铜、4圆石；合金混料炉保持2铁、1铜、5圆石、1熔炉。两台起步机器都不要求辅矿成品、陨相晶料、控制板或硼玻璃，避免“先造加工机才能做加工机原料”的循环。

## 准备寻找陨相矿

近距寻矿指示片由铜锭、红石、玻璃、硼盐各1制成，不再先消耗陨相晶料。采样镐、护目镜、绳索与采矿袋也使用辅料及常规材料，不要求先找到陨相。装备能力保持原范围：指示片只报告8格内有无信号；护目镜检查近距暴露矿；采样镐仍为10秒／块、每块4耐久的保晶工具。

陨相矿仍需铁镐以上。普通采收保持G6／12／24品位和I30—40，时运同时影响份数和品位概率；保晶采样与普通时运是不同采收方式。按已有整备工序加工原矿，得到通用晶料，用于省能接头、工具加固与后续精制。矿石稀有度尚未通过20种子校准。

## 陨相是工业提升的关键节点

基础整备台、混料炉、机架和寻矿准备保留无陨相起步路线。取得并加工第一份陨相后：

- 控制板ST-10、四类基础发电EN-G01—04、Ⅰ级提速SV-SP01和Ⅰ级扩批SV-BK01各额外消耗1份Q0通用晶料，服务端检查批次品质。
- 并列炉、自动合成台、物品抽取器和备用电源通过控制板继承陨相门槛；不能只用辅矿与原版材料建成完整电力自动化。
- Ⅱ级模块、更高品质精制、工程复合材料与20%／30%装备提升继续使用陨相及其衍生物。

基础煤驱动加工与手动供水仍能产出第一份晶料，不需要先造发电机来制造发电机原料。这里是材料与设备依赖，尚未用实际游玩计时证明平衡。

## 强化有明确晋升

| 路线 | 条件 | 最终耐久上限 |
| --- | --- | --- |
| 耐磨 | 普通镐＋赤钛耐磨镶片 | 原始耐久×110%，向下取整 |
| 陨相加固 | 普通镐或10%镐＋工具加固扣 | 原始耐久×120%，向下取整 |
| 复合强化 | 20%镐＋耐磨镶片＋硼玻璃＋烈焰粉 | 原始耐久×130%，向下取整 |

晋升替换同一升级位，不将110%再乘120%。损耗按旧损伤比例向上取整保留，名称、附魔及其他组件保留。同级不能重复安装，也不能从10%直接跳到30%。原版盾仍只有盾面衬片20%路线。

工作台或砂轮修理保留两件中已有的最高等级，不会把10%和20%合成30%。铁砧以左侧装备为目标。钻石镐锻造为下界合金时，按新材质2031基础耐久和原强化等级重算；10%／20%／30%上限分别为2234／2437／2640。旧带强化标记的装备会按已有耐久识别旧等级，无法识别的旧自定义上限保持兼容回退，读取本身不扩大其耐久。

## 从精制到复合材料

赤钛承担耐磨、结构和工装用途；灰硼承担绝缘、封装及玻璃材料用途。两者在中期共同进入导相、承载、层合及定向材料加工，再与真实陨相精制成分组合；不会因为是常规辅料就伪装成高完整度相材。

金用于进阶电控和精密部件，石英保留给后续定向与计量加工，黏液等生物材料提供可选工艺或特化用途。下界材料用于后期复合强化和选配件，首台设备、首次寻矿和基础精制起步不依赖首领战利品。耐温玻璃仍是可放置透明方块及实际装配原料，不宣称已有额外温度模拟机制。

装配时品质取参与的陨相与复合相材：P／I／O取最低值，污染取最高值，连续性取共同满足。钛粉、硼盐及普通结构料不提供相材品质，也不会把低质晶料抬成P100／I100。工业加工继续沿用原有门槛、按批耗水耗能、工具寿命、背压暂停和保存恢复。
