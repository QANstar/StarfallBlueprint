# 贝斯特首台可驾驶工程机甲：2026-10-29

## 本轮实现

新增独立实体`best_engineering_mech`与收纳物`best_mech`。机体宽1.8格、高3.2格，乘员附件高2.2格；原版模型层呈现原创双足、开放驾驶舱、辅助臂与固定钻臂。客户端注册渲染器、模型层、可重绑G键与骑乘HUD，服务端不加载客户端类。

`BestMechOperation`为独立个人知识；学习、制造、驾驶均校验本人三级研究、轻载通行与工务诊断。死亡复制保留知识。装配台新增第4页与动作17／18，不改变既有动作编号和库存布局。学习消耗承相结构嵌材4、导相铜复材板4、感相计量预坯2、控制板2；制造消耗普通钢32、承相结构嵌材16、导相铜复材板8、控制板4、钢制固定件16、钻石磨头2、感相计量预坯2、陶瓷护套8。库存副本完整校验后提交；无公共自动制造入口，不消耗已有能匣储能。

机体出厂无电，容量20,000,000 XH、生命100、磨损上限2400。原版乘骑输入由服务端处理：有资格、未隔离且资源可用时，实际地面移动消耗400 XH／刻并发热4；堵墙、待机不扣巡航能耗。自然冷却2／刻，热量1000锁止、冷至400恢复，100工作刻磨损1；无动力仍保留重力与下机路径。钻臂请求只接受实际驾驶者，不接受客户端指定实体或方块坐标；服务端视线、距离、铁级工具、方块实体与保护权限检查后走原版破坏事务，仅实际成功时消耗32,000 XH、热120、磨损1并进入20刻冷却。

部署检查承托、净空、实体碰撞、流体与世界边界。收纳要求隔离、无人、静止落地且背包有空间；保存生命、电量、热量、隔离、过热锁、磨损、累计工作刻、钻臂冷却、充电预算及名称。磨损耗尽仍可重新部署维修；毁坏机体保留零生命且不可通过部署复活。隔离检修使用普通钢恢复200磨损与5生命，水桶降热400并返空桶。收纳物可借副手诊断器切换隔离后，潜行长按对准基地储能取电，上限5000 XH／刻并受来源限流；实体接收上限512 XH／刻，同刻跨形态预算保留。每次实际取电前重新检查可取消的方块交互事件，空气开始使用后转向新来源也不能绕过交互拒绝。

两仓库生成源、图册、语言、32×32物品图标、128×128实体纹理与指南同步。固定钻臂原型是大型乘骑路线的基础；可替换躯干、肢体、核心与武器、重型及专项机体仍属后续开发。

```powershell
.\gradlew.bat '-PgameTestNamespaces=starfall_blueprint_mech,starfall_blueprint_diagnostics,starfall_blueprint_servicing,starfall_blueprint_mobility' build runGameTestServer
```

本机缓存环境：

```powershell
$env:JAVA_HOME='C:\Program Files\Java\jdk-21.0.12.1'
$env:PATH="$env:JAVA_HOME\bin;$env:PATH"
$env:GRADLE_USER_HOME='D:\Code\Workspace\.gradle'
$env:JAVA_TOOL_OPTIONS='-Djdk.net.hosts.file=D:/Code/Workspace/StarfallBlueprint/.tools/build-hosts'
.\gradlew.bat --offline --no-daemon -I .tools/mirror.init.gradle '-PgameTestNamespaces=starfall_blueprint_mech,starfall_blueprint_diagnostics,starfall_blueprint_servicing,starfall_blueprint_mobility' build runGameTestServer
```

环境为Java 21.0.12.1、Minecraft 1.21.1、NeoForge 21.1.262、Gradle 8.14.3。专用hosts引发Minecraft服务公钥请求的预期`UnknownHostException: api.minecraftservices.com`不代表测试失败；以GameTest汇总及Gradle退出状态判定。
