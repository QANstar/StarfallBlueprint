# 统一成长与科技

自2026-11-03起，模组已有的个人知识与科技研究统一从玩家背包的“成长”标签进入。生存背包与创造物品栏均提供入口；面板按“全部／贝斯特／岭川”分类，显示个人进度、前置、可用材料数量和所需经验等级。学习完成后，相应的制造、装备或驾驶权限立即使用原有知识判定。

当前注册并显示33项知识：贝斯特17项、岭川16项，包括两种基础机驾驶、汇流装配、六种可选组件和三种最终强化。当前没有个人知识门槛的公共配方继续按原材料与设备条件制作；本批不凭空给全部物品增加学习门槛。以后新增的个人成长、阵营科技、机甲驾驶及能力研究均接入同一节点目录与支付事务，不另造分散的学习入口。

## 操作与支付

成长界面采用全窗口树状画布：卡片按真实前置连线，已学习绿色、满足前置红色、未满足灰色。滚轮以鼠标位置缩放，左／中／右键拖动，单击选中；全览按钮或R恢复全树视野。可分别查看贝斯特与岭川分支；右侧详情独立滚动。节点显示对应装备／组件图标；只有学习按钮提交扣费，拖动、缩放和点选节点不会学习。材料仍由服务端从主背包／快捷栏取用，不需要在画布中拖动物品。

1. 打开背包，点击“成长”。选择分类与节点，查看前置、效果说明、材料和经验。
2. 准备主背包及快捷栏中的可用材料与足够经验等级。装备栏、副手和附近箱子不参与交付；污染材料或耐久已耗尽的物品不计数。
3. 点击“学习”。服务端重新检查本人知识、全部前置、材料、经验与玩家状态，成功后一次性交付材料、扣除等级并授予知识。材料或经验不足、前置缺失、重复点击等失败不扣任何费用。
4. 返回原工位进行制造、装配或维修。知识学习与实物制造是两个步骤，学会驾驶不会免费获得机甲。

经验费用的单位是**等级**，不是经验点；不同节点可以采用材料、经验或两者组合。当前贝斯特基础工务为零经验费用，其余节点按下表交付。创造模式可以查看面板，但不会免除学习费用。面板不要求站在工位旁，也不要求剧情任务、阵营身份或剧情许可。

个人研究统一从背包“成长”进入；贝斯特工务装配台提供同一面板的导航入口。研究消耗材料与经验，工位制造、装配和充电单独结算。

## 存档与多人

个人知识随正常存档及死亡重生保留，玩家之间不共享解锁。只维护当前节点和状态结构，不提供旧版知识迁移。

客户端仅提交当前菜单的节点索引，不提交价格或“已学习”状态。服务端只受理当前有效成长菜单中的学习点击；旧菜单、越界索引、死亡或旁观状态不能学习。面板展示的材料与知识是预览，结算以点击时的服务端状态为准。

## 后续开发约束

统一节点定义位于 `cn.starfall.blueprint.Progression`，通过 `register(Node)` 在初始化阶段注册稳定ID、分类、翻译、图标、前置ID、材料、经验费用、`Reward`物品与经验点奖励及知识读写函数。所有节点须在注册菜单前完成初始化，客户端和服务端使用相同目录与顺序；不得在游玩过程中改变目录。

后续技术调用统一预览与 `learn` 支付流程。知识授予只写对应的个人进度，不在授予回调中额外收费或再次改动库存。新增存档键必须补充死亡重生保留；当前节点不保留已删除路线的知识映射。新增设备可继续检查对应知识，但不得另设工位电力支付等旁路研究。制造、维修、装备实物安装和剧情事件不等同于个人知识节点；剧情模组的独立剧情状态不搬入技术本体。
